# cacaPalavraa

## Executar

Abra `prototipos.html` diretamente em um navegador. A página é autocontida e não precisa de instalação ou etapa de build.

O jogo permite digitar palpites, usar o teclado virtual, trocar entre três propostas visuais e escolher entre as dificuldades fácil, média e difícil. Os palpites são validados por um vocabulário local de demonstração; as estatísticas ficam apenas na sessão atual.
